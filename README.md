# WonkyInk

**看得很准，画得很歪。**

WonkyInk is an image-editing skill for turning an existing photo into a deliberately low-skill black gel-pen doodle while preserving the source scene, important details, and the attitude of prominent subjects.

> **Rich observation, dumb technique.**

WonkyInk is not a generic sketch filter. It aims for visibly irregular hand-drawn contours, crude symbolic shorthand, preserved scene identity, background presence at every gear, expression fidelity for prominent people, rich scenes without professional rendering, and minimal added text.

## Gear system

| Gear | Character |
|---|---|
| **Gear 1** | 极简笨拙挡 — very crude and simplified, while still keeping environment anchors |
| **Gear 2** | 轻松笨画挡 — loose and clumsy with a readable scene |
| **Gear 3** | 标准灵魂挡 — balanced default |
| **Gear 4** | 丰富笨画挡 — richer scene coverage with the same low-skill language |
| **Gear 5** | 爆满笨画挡 — maximum scene information, minimum local polish |

> **Lower gear compresses the background. It does not delete the background.**

> **Higher gear adds more observed things, not more drawing skill.**

## Usage

Load `SKILL.md`, provide a source image, and request a gear:

```text
WonkyInk Gear 1
```

```text
WonkyInk Gear 3
```

```text
WonkyInk Gear 5
```

The gear already bundles background retention, scene richness, clumsiness, local completion limits, and text restraint.

## Core rules

- **Keep the scene. Kill the polish.**
- **The line should look hand-guessed, not hand-traced.**
- **Readable shape, unsteady path.**
- **Few marks per object, many objects per scene.**
- **Simplify facial structure, not facial attitude.**
- **Richness comes from drawing, not writing.**

## Text policy

Added descriptive text is off by default. Existing signs and labels may be reduced to pseudo-text or short fragments. Extra playful text should only appear when explicitly requested.
